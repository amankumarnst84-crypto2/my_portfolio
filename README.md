# Aman Agrawal — Personal portfolio

A photo-led, responsive dark and lime portfolio, redesigned with scroll-linked parallax, entrance animations, photo scene switching, a rotating 3D skill visual, an interactive seven-technology explorer with code examples, expanded education and interest sections, and a horizontal photo gallery.

## Open locally

Open `index.html`, or run `python3 -m http.server 4173` and visit http://localhost:4173.

## Edit

- `index.html`: personal details, education, skills, project case study, photographs, and LinkedIn links.
- `style.css`: visual design, responsive layouts, and animation.
- `main.js`: technology content, 3D animation, scroll effects, photo switching, gallery controls, and accessibility.
- `images/`: locally prepared versions of the supplied photos.

All four newly supplied photos are used: IMG_1015 in the opening, IMG_1014 in the introduction and photo switcher, IMG_1005 in the opening switcher and gallery, and IMG_0995 in the motorcycle section. The motorcycle image is oriented in CSS. Originals are unchanged.

Google Fonts supplies Barlow Condensed and DM Sans; system fallback fonts are included. No external JavaScript dependencies. The motion control and reduced-motion system preference disable animation. The skill explorer supports arrow keys, Home, and End. The photo viewer supports arrow keys and Escape.

Additional projects and achievements will be added when Aman supplies them. The portfolio itself is the only featured project for now.

This version is local and is not published online. Publishing remains pending the earlier request for explicit authorization to upload the source and included personal photos.

The opening includes an animated AA logo and loading sweep, followed by an upward reveal. It automatically clears, can be skipped with Tab or Escape, and is disabled when reduced motion is preferred.
